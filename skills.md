# Skills

- Use C# and .NET to develop and maintain the OpenWeatherMap.Standard library.
- Work with OpenWeatherMap REST APIs to retrieve weather data by city, city ID, or ZIP code.
- Maintain the library's public models, enums, extensions, and REST service implementations.
- Build and test the library and its console, MVC, and Avalonia samples.
- Use the existing unit tests to verify weather lookup and ISO value behavior.
